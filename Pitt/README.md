Pitt Workspace

This directory contains the Speckit-aligned workspace for implementing
the Stock Analyzer Predictor project. Use this folder as the canonical
implementation workspace for spec-driven development.

Structure (high level):
- spec/: engineering specs and product specs
- docs/adr/: architecture decision records
- pkg/: implementation packages and modules
- scripts/: developer tooling and runbooks
- samples/: sample inputs and outputs
