Speckit Workspace Notes

This folder follows the Speckit methodology: specs-first development,
with directories for spec, implementation, docs and samples.

Conventions:
- `spec/` contains the authoritative engineering specification documents.
- `pkg/` contains implementation modules (python packages for the predictor).
- `docs/adr/` contains ADR markdown files.
- `scripts/` contains dev helpers and runbook scripts.
- `samples/` contains example JSON payloads and fixtures.
